# 🎬 Movie Ticket Booking – Python

## 📌 Overview

Movie Ticket Booking is a simple Python-based application that allows users to view available seats, book movie tickets, cancel bookings, and view booking summaries through a menu-driven interface.

This project demonstrates the implementation of basic booking operations and Python programming concepts in a real-world scenario.

## ✨ Features

* 🎟️ Book movie tickets
* 👀 View seat availability
* ❌ Cancel booked tickets
* 📊 Display booking summary
* 💰 Calculate total ticket revenue
* 🖥️ Simple command-line interface
* 🐍 Beginner-friendly Python project

## 🛠️ Technologies Used

* Python
* Functions
* Lists
* Loops
* Conditional Statements
* User Input Handling
